# AI Use Disclosure

This repository was developed with assistance from AI coding agents during the
WeMakeDevs × Bright Data "Into the Scrape-Verse" hackathon.

- **Agent used:** Codebuff (an AI coding assistant operating in the Freebuff
  desktop IDE) plus the human developer as reviewer and decision-maker.
- **What the agent did:** repository scaffolding, TypeScript/Next.js
  configuration, domain-model implementation, test authoring, refactoring,
  documentation drafts.
- **What the human did:** product direction, scope decisions, architecture
  lock, Bright Data account/collector configuration, demo orchestration,
  final review, and submission.
- **Verification:** all code in this repository is reviewed by the human
  maintainer; automated tests, typecheck, lint, and production builds are run
  in CI/local before every commit.
